# Guthaben in Issuing

## So machen Sie Gelder für Ihre Karten verfügbar.

Um Gelder für Kartenausgaben verfügbar zu machen, fügen Sie in Ihrem Konto zu Ihrem Guthaben in Issuing Gelder hinzu. Dieses Guthaben stellt für Issuing zurückgestellte Gelder dar und wird sicher von Ihren Einnahmen, Auszahlungen und Geldern aus anderen Stripe-Produkten getrennt.

#### Hinweis

Wenn Sie zur Finanzierung Ihres Issuing-Programms Stablecoin-Guthaben verwenden, erfahren Sie unter [Direkte Ausgaben von einem Non-Custodial Wallet](https://apidocs.bridge.xyz/platform/cards/overview/noncustodial), wie unser Smart Contract funktioniert. Die Methoden auf dieser Seite gelten für Fiat-finanzierte Issuing-Programme.

     

Mithilfe des Stripe-Dashboards oder der API können Sie auf das Bankkonto und die Bankleitzahl greifen, die Sie zum Überweisen von Geldern von Ihrem externen Bankkozunto benötigen. Wenn dieses Konto Gelder erhält, sind diese sofort als [Aufstockung](/api/topups) für das Issuing-Guthaben Ihres Stripe-Kontos verfügbar.

Die bereitgestellten Bankkontoangaben sind für eine bestimmte Währung eindeutig, und für das Konto kann eine unbegrenzte Anzahl von Geldeingängen erfolgen. Die Gelder kommen immer in der angegebenen Währung auf Ihrem Issuing-Guthaben an. In einigen Fällen führt Ihre Bank möglicherweise eine Währungsumrechnung durch.

| Region                     | Zahlungsschema                    | Unterstützte Währung | Geschwindigkeit                                 | Höchstbetrag akzeptiert                              |
| -------------------------- | --------------------------------- | -------------------- | ----------------------------------------------- | ---------------------------------------------------- |
| Vereinigte StaatenVorschau | Banküberweisung nur von US-Banken | USD                  | Zwischen einigen Minuten und einem Werktag      | Abhängig von der Bank, meist viele Millionen         |
|                            | ACH-Überweisung                   | USD                  | Zwischen wenigen Stunden und mehreren Werktagen | Abhängig von der Bank, in der Regel unter 25.000 USD |
| MitEurozone                | SEPA-Überweisung                  | EUR                  | Ungefähr ein Tag                                | 999.999.999,99 EUR                                   |
| Vereinigtes Königreich     | FPS                               | GBP                  | 1 Stunde                                        | 1 Mio. GBP                                           |
|                            | CHAPS                             | GBP                  | 1 Stunde                                        | Keine Obergrenze                                     |
|                            | Bacs                              | GBP                  | 2–3 Werktage                                    | 20 Mio. GBP                                          |

Verwenden Sie für die Push-Finanzierung im Vereinigten Königreich FPS für Überweisungen bis zu 1 Million GBP oder CHAPS für Überweisungen hoher Beträge ohne Obergrenze.
