## 1. 概述

帆软免费提供 [FineReport 软件](https://www.finereport.com/product/download) ，用户可使用该软件进行功能测试和试用。

* 直接下载的 FineReport 软件包含了所有功能，但是限制了并发数，使用部分功能时会存在试用信息标志。

* 用户可联系帆软商务，根据自己的需求购买功能点并注册。注册了的功能点可以使用，未购买的功能点无法使用。

注1：为保证正常使用，建议用户购买注册，FineReport 注册步骤请参考： [FineReport 服务器注册步骤](https://help.fanruan.com/finereport10.0/doc-view-280.html) 

注2：注册是有功能点区分的，即使注册了，如果没购买对应功能点，相关功能就无法使用，如果有需要可联系销售增购。

## 3. 未注册的影响

### 3.1 版权信息

如果 FineReport 未注册或者注册许可已经过期，用户通过 IP 或域名访问报表或数据分析，就会在报表底部显示版权信息：上BI选帆软，专注BI十三年，Powered by 帆软  使用模式。如下图所示：

注1：2019-12-05 及之后版本的 JAR 包才会显示报表版权信息。

注2：用户通过 localhost 或 127.0.0.1 访问报表或数据分析，不管是否注册都不会显示版权信息。

### 3.2 并发数

并发数指的是允许同时访问报表服务器的 IP 个数

未注册的并发数固定为 2 ，即同时只能有 2 个不同的 IP 访问服务器。如下图所示：

如正在访问服务器的 IP 数已达到最高并发数，后登录的用户将无法访问。

访问工程时报错：系统未注册或访问人数超过注册限制数量。

### 3.3 Web 应用服务器

未注册版本 Web 应用服务器每七天会暂停运行，报表无法正常访问，此时需要重启 Web 应用服务器如 Tomcat 。

如果您的项目正在进行中，上述未注册出现的暂停运行问题可能会对项目产生比较大的影响，甚至于出现不必要的损失。

因此，我们建议您购买 FineReport 报表软件，注册后再使用。

### 3.4 模板预览

若工程未注册，预览模板时随机出现该报错：您需要一个注册码或者该报表服务器的使用人数超过了注册限制的数量。
